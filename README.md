# Full Stack Employee Management System

A full-stack Employee Management System built using React.js, Node.js, Express.js, and MySQL.

## Features

* Add employees
* View employee details
* Update employee information
* Delete employees
* REST API integration
* MySQL database integration
* Separate frontend and backend

## Tech Stack

### Frontend

* React.js
* Axios
* CSS

### Backend

* Node.js
* Express.js
* REST APIs

### Database

* MySQL

## Project Structure

```text
FullStack-EMS/
├── client/
└── server/
```

## Application Flow

```text
React.js
   ↓
Axios API Request
   ↓
Express.js Routes
   ↓
Node.js Backend
   ↓
MySQL Database
   ↓
API Response
   ↓
React.js UI
```

## CRUD Operations

The application follows CRUD operations:

* **Create** — Add a new employee
* **Read** — Display employee information
* **Update** — Modify employee information
* **Delete** — Remove an employee

## Getting Started

Clone the repository and install the dependencies for both the client and server.

```bash
git clone https://github.com/satyajit-pradhan522/FullStack-EMS.git
```

Then start the frontend and backend separately.

## Purpose

This project demonstrates how a React frontend communicates with a Node.js and Express.js backend through REST APIs and stores employee data in a MySQL database.
